# Каталог автоматизаций

`automations/<id>/task.md` — единственное действующее описание поручения:
цель, scope, действия, ограничения, желаемое расписание и часовой пояс.
`state.md` — текущее состояние, предыдущий результат для сравнения, решения
владельца и привязка к одному исполнителю. Общий README содержит только навигацию.
Проектные знания остаются по карточкам; сюда помещаются ссылки на их владельцев.

Один запуск читает core, task.md и актуальный state.md, выполняет один проход
в разрешённых границах и сохраняет краткий результат. Перед записью перечитать
состояние, сохранить параллельные изменения. Нормативное поручение не переписывать
по собственной инициативе. Не выдавать план или отсутствие доступа за выполнение.

Создание, удаление, смена расписания, чата или полномочий требуют поручения
владельца. Расписание и доставка принадлежат выбранному приложению/исполнителю.
Запись в каталоге не устанавливает службу, не создаёт расписание и не разрешает
фоновый сбор памяти. При переносе проверить инструкцию и доступы, привязать нового
исполнителя и отключить старого, не оставляя два активных расписания одной задачи.

Для heartbeat уведомлять о существенном изменении, завершении, сбое или нужном
действии владельца; неизменившееся несущественное состояние не требует сообщения,
если пользователь не задал другой формат. Обновление state не разрешает менять
исследуемый проект, удалять файлы, подключать аккаунты или публиковать материалы.
Политика синхронизации задаётся владельцем экземпляра; чужие разрешения не наследуются.

Шаблоны: `templates/automation-task.md`, `templates/automation-state.md`.
Установка не копирует задачи, аккаунты, session IDs и расписания другого владельца.
