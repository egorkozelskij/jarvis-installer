# Generic adapter

An agent without automatic skill discovery reads root AGENTS.md, the core
router and selected module instructions explicitly. Use numbered answers if
interactive forms are absent. The deterministic installer has a JSON interface;
it does not itself render native checkboxes. Unsupported tools are reported,
not simulated as successful integrations.

To reuse a shared memory in another chat, explicitly load that instance's
entrypoint in the new client. Available-chat history capture requires the
owner's separate choice and actual list/read tools in that host. Preserve
coverage and continuation markers; do not infer that an unavailable source
was read. The communicating agent retains justified useful information itself;
no periodic memory process is required. Global configuration remains separate setup.
