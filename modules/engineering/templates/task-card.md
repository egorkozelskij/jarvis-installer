# Task card

Goal: what should improve, in one sentence.
Scope: project, branch or package; repositories that may change.
Keep: public API and observable behavior that must not change
      (ordering, errors, resource release, memory limits, formats).
Rules: applicable rule IDs.
First: how equivalence or correctness will be checked.
Then: what will be measured or reviewed, if anything.
Result: patch, check results, open questions and the next condition.
Budget: time or attempts allowed before stopping and reporting.
Not allowed: commit / push / release / deploy unless listed here by the owner.
