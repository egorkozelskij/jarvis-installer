### AREA-TOPIC-001 — Short statement of the requirement

- Scope: exact project branch, package or path.
- Invariant: the property that must hold, stated so it can be checked.
- Safe path: the normal way to satisfy it.
- Forbidden: the shortcut this rule excludes.
- Evidence: `static` | `contract` | `runtime` | `review` — how compliance is shown.
- Reason: the problem that made this rule necessary.
