---
name: jarvis-computer-guide
description: Help choose optional computer-control tools for the owner's OS. This release provides setup guidance and does not install remote access or change host permissions.
---

Check the actual OS and available host tools. Do not assume macOS accessibility
permissions exist or that Windows needs WinAuto. Prefer existing supported tools;
OS utilities are optional adapters. Explain access scope and revocation before
installation. Remote access, unattended execution and network exposure need
separate explicit choices. Never disable OS protections or bypass a sandbox to
remove a visual frame. Verify operation on the real platform before claiming it.
